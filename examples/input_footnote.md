# 각주 다는 법

## 번호를 놓는 자리

□ 각주 번호는 근거가 되는 말 바로 뒤에, 빈칸 없이 붙여 쓴다[^1]
○ 문장 전체의 근거이면 마침표 앞에 둔다[^2]
- 국내 학술지·정부 보고서의 관행이다
- 시카고식(마침표 뒤)을 쓰려면 프로파일에서 바꾼다
○ 인용문 자체가 각주 대상이면 닫는 따옴표 안에 넣는다 — "노인 빈곤은 구조적 문제다[^3]"
- 인용을 쓴 문장 쪽의 근거이면 따옴표 밖에 둔다
- 도구는 이 둘을 구분하지 못하므로 검사하지 않는다

□ 각주 내용은 문서 어디에 적어도 된다
○ 라벨은 이름표일 뿐이고 인쇄되는 번호는 한글이 문서 순서대로 매긴다
- 라벨과 실제 번호가 어긋나면 검사가 알려 준다
- 같은 각주를 두 번 부르면 각주가 두 개 만들어진다
○ 부르지 않은 각주와 내용 없는 각주는 검사에서 걸린다
- 내용을 찾지 못한 자리표는 본문에 그대로 남겨 눈에 띄게 한다
- 표 안과 도식 상자 안에는 각주를 달 수 없다

[^1]: 통계청(2024), 「가계금융복지조사」, 국가통계포털.
[^2]: 보건복지부(2025), 『노인실태조사』, 87쪽.
[^3]: OECD(2024), Pensions at a Glance 2024, p.32.
