# 통합 정보시스템 구축

## 자료 관리 체계

□ 데이터베이스 구성

○ 회원·신청·사업 세 테이블로 나누어 보관

- 회원 정보는 신청 이력과 분리해 개인정보 접근 범위를 좁힘
- 사업코드는 소관부처 코드체계를 그대로 따름

:::diagram type=db title="지원사업 DB 구성"
[회원]
  *회원ID
  이름
  생년월일
  연락처
[신청]
  *신청ID
  +회원ID
  +사업코드
  신청일
  처리상태
[사업]
  *사업코드
  사업명
  소관부처
회원 → 신청 → 사업
:::

○ 신청 테이블이 회원과 사업을 잇는 중심 테이블

- 한 회원이 여러 사업에 신청할 수 있어 신청ID를 따로 둠
- 처리상태는 접수·심사·결정·지급 네 값만 허용

□ 신청 처리 절차

○ 접수부터 지급까지 다섯 단계로 운영

- 자격 확인은 행정정보 공동이용으로 처리해 서류 제출을 줄임
- 심의 결과는 신청 테이블의 처리상태에 기록

○ 단계마다 처리 기한을 두어 지연을 막음

- 접수·자격 확인은 3일, 심의는 14일 이내
- 기한을 넘기면 담당자에게 알림이 간다

:::diagram type=flow title="신청 처리 절차"
접수 → 자격 확인 → 심의 → 결정 통보 → 지급
:::

□ 추진 체계

○ 기획반이 표준을 정하고 구축반이 구현

- 자료 표준과 코드체계는 기획반 표준팀이 관리
- 설계팀은 화면·기능 설계를 맡음

○ 자문위원회는 분기마다 자문 의견을 제출

- 개인정보 보호와 자료 연계 범위를 중점 검토
- 의견은 다음 분기 계획에 반영
