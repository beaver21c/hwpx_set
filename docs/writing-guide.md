# 본문 작성법 (마커 텍스트)

hwpx-studio의 본문 입력은 **한 줄에 한 항목**인 평범한 텍스트다. 줄머리에 마커를
붙이면 그 줄의 서식(레벨)이 정해진다. 워드프로세서 없이 메모장·채팅창·AI 어디서든
쓸 수 있고, 사람이 직접 고치기도 쉽다.

## 1. 줄머리 마커

기본 프로파일(`policy-default`) 기준이다. 마커는 프로파일에서 바꿀 수 있다.

| 입력 | 결과 | 용도 |
|---|---|---|
| `# 제목` | Ⅰ. 제목 | 장 (로마자 자동 번호) |
| `## 제목` | 1. 제목 | 절 (숫자 자동 번호) |
| `□ 내용` | □ 내용 | 주제 |
| `○ 내용` | ○ 내용 | 주요 |
| `- 내용` | - 내용 | 설명 |
| `· 내용` | · 내용 | 세부 |
| `※ 내용` | ※ 내용 | 참고 |

규칙은 하나다. **마커 뒤에 공백 한 칸.** 그래서 `전년 대비 -3% 감소` 같은 문장은
마커로 오인되지 않는다.

번호(`Ⅰ.`, `1.`)는 도구가 붙인다. 본문에 직접 쓰지 않는다.

## 2. 빈 줄·표·그림

- **빈 줄**: 블록을 나눈다. 표·도식 앞뒤에는 빈 줄을 둔다
- **표**: 파이프 기호로 쓴다. 첫 행이 머리행이 되고, `|---|` 구분선은 무시된다

```
| 구분 | 목표 | 실적 |
|---|---|---|
| 처리 기간 | 14일 | 11일 |
```

- **그림**: `![](경로.png)` — 프로파일의 기본 폭(mm)으로 비율을 유지해 넣는다
- **도식**: `:::diagram` 블록 → `docs/diagram-guide.md`

## 3. 각주

근거가 되는 **말 바로 뒤에 붙여** `[^라벨]`을 적고, 내용은 아무 데나 `[^라벨]: …`
줄로 적는다. 내용 줄은 본문에 나오지 않는다.

```
□ 노인 빈곤율은 40.4%로 가장 높다[^1]

[^1]: 통계청(2024), 「가계금융복지조사」.
```

- 한글의 **진짜 각주**로 들어간다(쪽 아래 + 자동 번호). **8pt 회색**이다
- 라벨은 이름표일 뿐, 인쇄되는 번호는 한글이 문서 순서대로 매긴다
- **번호 자리**: 앞말에 붙여 쓰고, 문장 전체의 근거면 마침표 **앞**
  (`…한다[^1].`), 인용은 따옴표를 **닫은 뒤**(`"…"[^1]`)
- 제목·표 안·도식 상자 안에는 달지 않는다

자세히: `docs/footnote-guide.md`

## 4. 마커를 안 쓴 줄

- 서술식(`mode: narrative`) 프로파일에서는 `#`/`##`만 제목이고, 나머지 줄은 본문 문단이 된다
- 개조식에서 마커 없는 줄은 **들여쓰기 2칸 = 한 단계**로 해석해 레벨을 추정하고 경고를 남긴다.
  마크다운 습관(`- `, `* `)으로 쓴 목록도 이렇게 흡수된다

## 5. 검사(lint)

`hwpx-studio lint input.md -p profiles/policy-default.json`

| 코드 | 내용 |
|---|---|
| `balance` | 상위 항목 아래 하위 항목 수가 규칙(`rules.min_children`)보다 적음 |
| `period` | 온점 규칙 위반(단문 온점, 두 문장 이상 온점 누락) |
| `symbol` | 본문 중간에 레벨 기호를 단독으로 씀 |
| `jump` | 중간 레벨을 건너뜀(□ 다음 바로 ·) |
| `spacing` | 표·도식 앞뒤 빈 줄 없음 |
| `footnote` | 각주 번호 자리(빈칸·마침표 앞뒤·인용부호·제목) |
| `parser` | 마커 중복, 들여쓰기 폴백, 각주 내용 없음·안 부름 등 파싱 단계 경고 |

`--strict`를 주면 경고도 오류로 취급해 생성을 중단한다.

## 6. 개조식 작성 요령

- 한 항목 한 줄. 두 줄이 필요하면 하위 레벨로 내린다
- 단문은 온점 생략, 두 문장 이상이면 온점을 찍는다
- 경어체를 쓰지 않는다(“~함”, “~임” 또는 명사형 종결)
- 상위 항목 아래에는 하위 항목을 2개 이상 둔다. 1개뿐이면 상위와 합친다
- 확인되지 않은 수치·출처는 쓰지 말고 `[확인 필요]`로 표시한다

## 7. AI에게 본문을 시킬 때

`hwpx-studio export-skill`이 만들어 주는 `prompt.txt`를 그대로 붙여넣으면 된다.
프로파일의 마커·균형 규칙이 반영된 지시문이 나온다.

```
아래 규칙으로 보고서 본문만 텍스트로 작성. 서식 설명·코드블록 금지.
줄머리 마커: "□ "=네모, "○ "=원, "- "=하이픈, "· "=점, "※ "=참고. 마커 뒤 공백 1칸.
...
```
