# 도식(조직도·체계도·절차도) 작성 안내

이 문서는 hwpx-studio로 한글(.hwpx) 문서 안에 조직도·체계도·절차도를 넣는 방법을
설명한다. 프로그래밍 지식은 필요 없다.

---

## 1. 클릭으로 그리는가, 글로 쓰는가

**글로 쓴다.** 마우스로 상자를 하나씩 놓고 선을 잇는 방식이 아니라, 메모장에 목록을
쓰듯 구조를 적으면 도구가 배치와 연결선을 자동으로 계산해 한글 문서에 넣는다.

| 방식 | 한글 프로그램에서 직접 그리기 | hwpx-studio(이 도구) |
|---|---|---|
| 작업 | 표 삽입 → 셀 병합 → 셀마다 테두리 끄고 켜기 → 글자 입력, 또는 그리기 개체(사각형·선)를 하나씩 배치·정렬 | 들여쓰기 목록 6~10줄 작성 |
| 소요 | 상자 5개 기준 수십 회 클릭 [일반적 경험] | 타자 1분 |
| 수정 | 상자 추가 시 주변 정렬 다시 | 목록에 한 줄 추가 후 재생성 |
| 결과물 | 표 또는 그리기 개체 | **표**(기본) 또는 그림 |
| AI 활용 | 불가 | 어떤 AI에든 "아래 형식으로 조직도 써줘"로 생성 가능 |

생성된 도식은 한글에서 **보통의 표**이므로, 이후 한글에서 글자를 고치거나 행을
추가하는 것은 평소 표 편집과 같다.

---

## 2. 기본 형식

보고서 본문 텍스트 안에 `:::diagram` 으로 시작해 `:::` 으로 끝나는 블록을 넣는다.

### 2.1 조직도·체계도 (`type=org`)

위에서 아래로 내려가는 계층 구조. **들여쓰기 2칸**이 한 단계 아래를 뜻한다.

```
:::diagram type=org title="조직 체계"
대표
  기획부
    기획팀
    예산팀
  운영부
  연구부
:::
```

결과: 맨 위 "대표", 그 아래 가로로 기획부·운영부·연구부, 기획부 아래 기획팀·예산팀.
연결선은 자동이며 **상자의 가운데**에서 내려온다.

체계도(예: 추진 체계, 전달 체계)도 같은 형식으로 쓴다. 최상위에 총괄 기구, 아래에
하위 기구를 나열하면 된다.

### 2.2 절차도·흐름도 (`type=flow`)

왼쪽에서 오른쪽(기본) 또는 위에서 아래로 흐르는 단계.

```
:::diagram type=flow
접수 → 검토 → 심의 → 통보
:::
```

세로 배치: `:::diagram type=flow direction=down`
화살표는 `→`, `->`, `=>`, `>` 무엇을 써도 인식한다.

### 2.3 매트릭스·비교표 (`type=matrix`)

행·열로 구분되는 격자. 첫 행·첫 열이 제목 칸이 된다.

```
:::diagram type=matrix title="역할 분담"
| | 중앙 | 지방 |
| 기획 | 본부 | 지역본부 |
| 집행 | 사업단 | 현장사무소 |
:::
```

## 3. 옵션

| 옵션 | 값 | 설명 |
|---|---|---|
| `title="…"` | 문자열 | 도식 아래에 붙는 제목 |
| `render=table` (기본) | table / image | table: 한글에서 편집 가능한 표. image: PNG로 그려 삽입 |
| `direction=right` | right / down | flow 전용. 진행 방향 |
| `width=160` | mm | 도식 최대 폭. 넘치면 자동 축소, 그래도 넘치면 image로 전환 |

상자 색·선 굵기·글자 크기는 블록마다 쓰지 않고 **프로파일(JSON)의 `diagram` 항목**에서
한 번만 정한다. 문서 전체의 도식이 같은 모양으로 나온다.

| 프로파일 항목 | 뜻 |
|---|---|
| `box_fill` / `box_border` | 상자 채움색 / 테두리색 |
| `root_fill` / `root_color` | 최상위 상자의 채움색 / 글자색 |
| `col_width_mm` / `col_gap_mm` | 상자 폭 / 상자 사이 간격 |
| `row_height_mm` / `row_gap_mm` | 상자 높이 / 단계 사이 간격 |
| `max_width_mm` | 최대 폭(넘으면 축소 후 이미지 폴백) |
| `grid_resolution` | 상자 하나가 차지하는 열 수(짝수, 기본 6). 클수록 연결선 위치가 정밀해지지만 표의 열이 많아진다 |

---

## 4. 어떻게 그려지는가(참고)

표 방식은 **균일한 폭의 열**로 격자를 만든다.

- 상자 = `grid_resolution`개의 열을 병합한 셀(채움색 + 4변 테두리)
- 병합 구간의 한가운데가 곧 열 경계 → 그 경계가 상자의 중심선
- 세로 연결선 = 그 경계에 해당하는 셀의 **오른쪽 변** 테두리
- 가로 버스 = 자식들 중심 사이 셀들의 **위쪽 변** 테두리
- 나머지 셀 = 테두리 없는 투명 셀

부모의 중심은 자식 중심들의 중간값이라 열 폭이 균일하면 항상 유효한 열 경계에
떨어진다. 그래서 깊이·자식 수와 무관하게 연결선이 상자 가운데에 맞는다.

가로 버스는 연결 행의 **위쪽 변**에 그린다. 그 위치가 부모 세로선이 끝나는 경계와
같아서 선이 끊기지 않는다(아래쪽 변에 그리면 한 행만큼 어긋난다).

## 5. 잘 안 될 때

| 증상 | 원인 | 조치 |
|---|---|---|
| 한 줄이 같은 단계로 붙어 나옴 | 들여쓰기가 일정하지 않음(탭·1칸·3칸 혼용) | 2칸 공백으로 통일 |
| 가로가 잘려 보임 | 같은 단계의 상자가 너무 많음 | `width` 늘리기, 일부를 하위로 내리기, 또는 `render=image` |
| 연결선이 안 보임 | 한 변 테두리 자체는 한글에서 표시되는 것을 확인했다. 버전·뷰어에 따른 차이가 의심되면 | `render=image` 로 전환 |
| 화살표가 필요함 | table 방식은 직선만 지원 | `render=image` 사용, 또는 flow의 `→` 문자 활용 |
| 상자 글자가 두 줄로 꺾임 | 이름이 셀 폭보다 김 | 프로파일 `diagram.col_width_mm` 늘리기 또는 이름 줄이기 |
| 이미지 도식의 한글이 네모로 나옴 | matplotlib에 한글 글꼴 없음 | `apt install fonts-nanum` 또는 `pip install koreanize-matplotlib` 후 재실행 |
| `render=image`인데 표로 나옴 | matplotlib 미설치 | `pip install hwpx-studio[image]` (경고 메시지로도 안내된다) |

## 6. 한글에서 직접 그릴 때(참고)

이 도구 없이 한글 프로그램에서 같은 도식을 만들려면 일반적으로 두 가지 방법을 쓴다
[일반 지식, 메뉴명·위치는 버전별 상이].

- 표 방식: 표를 넓게 삽입 → 필요한 셀만 남기고 테두리를 없앰 → 연결선이 될 셀의 한 변만
  테두리를 켬 → 상자 셀에 배경색·글자. 이 도구의 `render=table`이 이 과정을 자동화한 것
- 그리기 개체 방식: 사각형과 직선을 개별 삽입 → 위치·크기를 정렬 → 사각형 안에 글자.
  자유롭지만 수정 시 재정렬 필요

둘 다 가능하지만, 보고서에 반복 삽입하거나 조직 개편 때마다 갱신해야 한다면 텍스트
블록으로 관리하는 편이 유리하다.
