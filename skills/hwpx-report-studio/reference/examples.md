# 작성 예시 모음

가장 흔하게 발생하는 오류와 올바른 작성법을 비교한다.

## 자동 부여 기호 중복

줄머리 마커가 곧 그 기호다. 마커 뒤에 같은 기호를 또 쓰면 출력에 두 번 나타난다.
검사가 "마커가 중복 입력됨"으로 잡아내지만, 애초에 쓰지 않는 것이 맞다.

### 잘못된 예

```
□ □ 【배경 1】 정책 수요 변화   ← □는 자동, 중복
○ ○ (1) 고령화 심화   ← ○는 자동, 중복
- - 65세 이상 인구 비율 20% 초과   ← -는 자동, 중복
· · 고독사 위험군 모니터링 확대   ← ·는 자동, 중복
※ ※ ○○청, 2024   ← ※는 자동, 중복
```

### 올바른 예

```
□ 【배경 1】 정책 수요 변화   ← □는 엔진이 자동으로 붙임
○ (1) 고령화 심화   ← ○는 엔진이 자동으로 붙임
- 65세 이상 인구 비율 20% 초과   ← -는 엔진이 자동으로 붙임
· 고독사 위험군 모니터링 확대   ← ·는 엔진이 자동으로 붙임
※ ○○청, 2024   ← ※는 엔진이 자동으로 붙임
```

## 자동 번호 중복

로마자(`Ⅰ. Ⅱ. Ⅲ.`)와 숫자(`1. 2. 3.`)도 자동 부여이므로 본문에 포함시키지 않는다.

### 잘못된 예

```
# Ⅰ. 서론   ← Ⅱ. 정책 현황
## 1. 배경 및 필요성
```

### 올바른 예

```
# 서론   ← 정책 현황
## 배경 및 필요성
```

## 머릿글 누락

네모(`□`)와 원(`○`)은 분류 머릿글이 반드시 필요하다.

### 잘못된 예

```
□ 정책 수요 변화   ← 【】 누락
○ 고령화 심화   ← () 누락
```

### 올바른 예

```
□ 【배경 1】 정책 수요 변화
○ (1) 고령화 심화
```

## 온점 처리

단문이면 온점 없음, 복문이면 온점 삽입.

### 잘못된 예

```
- 65세 이상 인구 비율 20% 초과.   ← 단문에 온점
- 참여 집단 취업 성공률은 54.2%에서 68.7%로 상승 미참여 집단 대비 유의한 차이 확인   ← 두 문장인데 사이 온점 없음
```

### 올바른 예

```
- 65세 이상 인구 비율 20% 초과   ← 단문, 온점 없음
- 참여 집단 취업 성공률은 54.2%에서 68.7%로 상승. 미참여 집단 대비 유의한 차이 확인   ← 문장 사이 온점, 끝 단문은 온점 없음
```

## 경어체·종결 어미 사용

연구 보고서이므로 평서·개조식만 사용한다.

### 잘못된 예

```
- 65세 이상 인구 비율이 20%를 초과했습니다   ← 경어체
- 65세 이상 인구 비율이 20%를 초과하였다   ← 종결 어미
```

### 올바른 예

```
- 65세 이상 인구 비율 20% 초과
```

## 레벨 오용

일반 본문을 점(`·`)까지 펼치거나, 본문 내용을 참고(`5`)에 넣으면 안 된다.

### 잘못된 예

```
○ (1) 고령화 심화
- 65세 이상 인구 비율 상승
· 구체적 수치는 ○○청 자료 참조   ← 본문 핵심을 점으로 미룸
· 관련 정책은 다음 절에서 설명   ← 메타 설명
※ 고령화 정책 예산은 전년 대비 12% 증가   ← 본문 내용을 참고로 분류
```

### 올바른 예

```
○ (1) 고령화 심화
- 65세 이상 인구 비율 20% 초과
- 고령화 정책 예산 전년 대비 12% 증가
· 특히 돌봄 서비스 예산이 18% 비중 차지
※ ○○청, 「2024 고령자 통계」   ← 출처 보조 정보
```

## 전체 흐름 예시

장 하나의 도입~본문~표가 함께 있는 전형적 구조이다.

```
# 정책 현황   ← # 배경 및 필요성
□ 【배경 1】 정책 수요 변화
○ (1) 고령화 심화
- 65세 이상 인구 비율 20% 초과
- 돌봄 서비스 수요 급증
○ (2) 1인 가구 증가
- 1인 가구 비중 35% 도달
- 사회적 고립 위험 상승
· 고독사 위험군 모니터링 대상 전년 대비 2.3배 확대
□ 【배경 2】 정책 환경 변화
○ (1) 재정 여건 악화
- 복지 예산 비중 GDP 대비 15% 도달
- 신규 재원 확보 한계
○ (2) 디지털 전환 가속
- 비대면 서비스 수요 확대
- 데이터 기반 정책 결정 비중 증가

| 구분 | 2023 | 2024 | 2025 |
|---|---|---|---|
| 복지 예산(조 원) | 100 | 115 | 128 |
| GDP 대비 비중(%) | 12.8 | 13.6 | 15.0 |

※ □□부, 「국가재정운용계획 2025-2029」
```

들여쓰기는 하지 않는다. **줄머리 마커가 곧 계층**이라, 앞에 공백을 넣으면 안 된다
(도식 블록 안에서만 들여쓰기가 계층을 뜻한다).
