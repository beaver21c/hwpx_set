# 레벨 체계 상세

본문 각 줄은 **줄머리 마커 + 공백 한 칸 + 내용**이다. 각 레벨이 문서 구조에서 맡는 역할이 명확하므로, 본문 내용의 성격에 맞는 레벨을 정확히 선택해야 한다.

## 레벨별 용법

### 로마자 (`#`)
- 문서의 대분류 장
- 예: "Ⅰ. 서론", "Ⅱ. 정책 현황", "Ⅲ. 결론"
- 번호 `Ⅰ. Ⅱ. Ⅲ.`는 도구가 붙이므로 본문에 쓰지 않음

### 숫자 (`##`)
- 장 내부 소절 구분
- 예: "1. 배경 및 필요성", "2. 선행 연구"
- 기호 `1. 2. 3.`는 자동 부여

### 네모 (`□`)
- 해당 절에서 다룰 주제 선언
- 항목을 분류·요약하는 머릿글을 `【】`로 감싸 문장 앞에 배치
- 머릿글은 짧은 명사구(카테고리명 + 번호 또는 키워드)
- 예
  ```
□ 【전환 3】 단일 중앙 AI 의존
□ 【쟁점 1】 개인정보 보호 범위
```

### 원 (`○`)
- 그 주제의 핵심 본문
- 항목을 분류·요약하는 머릿글을 `()`로 감싸 문장 앞에 배치
- 머릿글은 짧은 축·키워드 표현
- 예
  ```
○ (1축) 선제적·수요중심 AI 도입
○ (a) 예산 집행률 92.4% 달성
```

### 하이픈 (`-`)
- 원에 대한 구체적 설명
- 일반 본문은 이 레벨에서 종결되는 것이 원칙
- 머릿글 규칙 없음. 본문만 작성

### 점 (`·`)
- 하이픈만으로 부족할 때, 세부·구체 사례를 한 단계 더 펼칠 때만 사용
- 모든 본문을 점까지 펼치면 문서가 산만해지므로 절제하여 사용
- 머릿글 규칙 없음

### 참고 (`※`)
- 본문 흐름과 분리된 보조 정보에만 사용
- 용도: 용어 정의, 유사 정책·제도 사례, 근거 자료 출처 등
- 본문에 직접 포함시키기에 부적절하나 독자에게 유익한 정보
- 머릿글 규칙 없음

### 빈 줄
- 형식: `(여기서 한 줄 비움)`
- 장·절 전환 지점, 표·그림 전후에 배치
- 가독성 확보용

## 특수 요소 상세

### 표

- 형식: 파이프 표(`| 구분 | 값 |`). 둘째 줄은 `|---|---|`
- 첫 행이 자동 헤더(파란 배경·흰 볼드) 처리
- 첫 행이 자동으로 머리행이 된다
- 표 앞뒤에 `(여기서 한 줄 비움)` 배치 권장

예시

```
(여기서 한 줄 비움)

| 구분 | 2023 | 2024 | 2025 |
|---|---|---|---|
| A사업 | 100 | 120 | 145 |
| B사업 | 80 | 90 | 105 |

(여기서 한 줄 비움)
```

### 그림

- 형식: `![](파일경로)`
- 기본 가로 폭 120mm, 비율 자동 유지
- 실제 파일이 존재해야 함. 없는 경우 추가하지 말 것
- 가상의 그림 경로를 임의로 만들지 않는다

```
![](/path/to/figure1.png)
```

## 레벨 선택 가이드

본문을 작성하다가 어느 레벨을 써야 할지 헷갈릴 때 다음 기준으로 판단한다.

- "이 문장은 어떤 주제를 던지는가?" → 네모
- "그 주제의 핵심 내용인가?" → 원
- "원에서 던진 내용을 풀어 설명하는가?" → 하이픈
- "하이픈의 세부 사례·구체 수치인가?" → 점
- "본문 흐름에서 잠깐 빠진 보조 설명·근거인가?" → 참고
