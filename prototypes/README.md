# 프로토타입 · 검증 자료

## orgchart_table.hwpx

설계 명세 §2.2 실험 C에서 **수작업 좌표**로 만든 표 기반 조직도다(대표 → 기획부/운영부/연구부).
연결선을 셀의 한 변 테두리로 그렸을 때 XML이 정상 생성되는 것까지 확인했다.

- 확인됨: XML 구조(셀 병합·한 변 테두리·투명 셀)
- **미확인: 한글(뷰어) 화면에서 연결선이 실제로 보이는지** — 설계 명세 M7-0

이 파일을 한글 또는 한글 뷰어에서 열어 연결선 표시 여부를 확인해야 한다.
표시되지 않으면 `docs/diagram-guide.md`의 대안(연결선을 배경색 셀로 대체, 또는
`render=image`)을 기본값으로 바꾼다.

현재 구현(`hwpx_studio/diagram.py`)은 이 프로토타입과 두 가지가 다르다.

| 항목 | 프로토타입 | 현재 구현 |
|---|---|---|
| 상자 | 셀 1개 | 열 `grid_resolution`개(기본 6) 병합 |
| 연결선 위치 | 상자의 왼쪽 변 | 상자의 **가운데**(병합 경계) |
| 좌표 | 수작업 | 트리 → 격자 자동 계산 |

같은 도식을 현재 구현으로 다시 만들려면:

```bash
hwpx-studio diagram "대표 > 기획부, 운영부, 연구부" -o org_new.hwpx
```
