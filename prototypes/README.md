# 프로토타입 · 검증 자료

## orgchart_table.hwpx

설계 명세 §2.2 실험 C에서 **수작업 좌표**로 만든 표 기반 조직도다(대표 → 기획부/운영부/연구부).

### 확인 결과: 연결선은 한글에서 표시된다 ✔

한글(모바일 뷰어)에서 열어 확인한 결과, **셀 한 변 테두리로 그린 연결선이 정상 표시된다.**
따라서 도식 기본 렌더는 표(`render=table`)를 유지한다. 명세 §7.4의 대안(배경색 셀 대체)은
필요 없다.

다만 이 프로토타입 자체는 아래 두 가지가 어긋나 보인다. 둘 다 현재 구현에서 해결했다.

| 증상 | 원인(XML 근거) | 현재 구현 |
|---|---|---|
| 연결선이 상자 **왼쪽 변**에 붙음 | 상자가 셀 1개(col4)이고, 세로선은 col3의 `right` 테두리 → 상자 왼쪽 모서리 | 상자를 짝수 개 열(`grid_resolution`, 기본 6)로 병합하고 그 **병합 경계**를 중심선으로 사용 |
| 부모 세로선과 가로 버스가 **끊겨 보임** | 버스를 row2의 `bottom` 테두리로 그려, row1에서 끝난 세로선보다 한 행(3600 HWPUNIT ≈ 12.7mm) 아래에 놓임 | 버스를 연결 행의 `top` 테두리로 그림 → 세로선이 끝나는 경계와 정확히 맞물림 |

즉 3번 파일(이 프로토타입)이 어긋나 보이는 것은 한글의 표시 문제가 아니라 **프로토타입의
좌표 설계 문제**다.

### 같은 도식을 현재 구현으로 다시 만들기

```bash
hwpx-studio diagram "대표 > 기획부, 운영부, 연구부" -o org_new.hwpx
```

| 항목 | 프로토타입 | 현재 구현 |
|---|---|---|
| 상자 | 셀 1개 | 열 `grid_resolution`개(기본 6) 병합 |
| 연결선 위치 | 상자의 왼쪽 변 | 상자의 **가운데**(병합 경계) |
| 가로 버스 | 아래쪽 변(`bottom`) → 세로선과 한 행 어긋남 | 위쪽 변(`top`) → 세로선과 연결 |
| 좌표 | 수작업 | 트리 → 격자 자동 계산 |
